- Toda afirmación normativa lleva cita (id BOE + artículo). Sin cita, no se responde.
- Importes y puntos salen solo de la tabla ARCI (y de los tramos del Anexo IV de la LSV para velocidad); el LLM nunca los genera.
- eval/questions.yaml es el contrato: cualquier cambio de prompt/modelo se evalúa antes del merge.
- Aviso legal visible en UI y en la respuesta del MCP.
- Corpus v1: solo RGC (CIR) y LSV. Las filas ARCI de otras normas no se cargan.
- `data/trafico.db` se genera (no se versiona), en este orden: `uv run python -m trafico_agent.ingest.arci`, `... .ingest.boe` (necesita acceso a www.boe.es) y `... .ingest.postproceso` (cruce sanciones↔artículos y `fragmentos`).
- La clave de un artículo es `(id_norma, id_bloque)`: el número no es único (RGC art. 151–158 duplicados, articulado propio del Anexo II).
- Recuperación (`index.py`): BM25 sin extras; vectores y reranker con `uv sync --extra ml` y `uv run python -m trafico_agent.index` (genera `data/embeddings.npy`). Métricas: `uv run python eval/run_retrieval.py` → `eval/results/retrieval.json`.
- Agente (`agent.py`, LangGraph): LLM solo en analizar, elegir fila ARCI y redactar; `llm.py` da la firma `llm(sistema, usuario, esquema)`. Modelo local por defecto `qwen2.5:7b` en Ollama (`TRAFICO_MODELO`); el pequeño evaluado para CPU es `qwen2.5:3b` (notas/s3-agente.md); la demo publicada usa `gpt-oss-120b` por API (ver abajo). Tema, vehículo y cifras salen de reglas (`extraer_datos`), no del LLM. Evaluación: `uv run python eval/run_agent.py --tipo situacion`.
- Tests sin red: la ingesta del BOE se prueba con `tests/fixtures/boe/`.
- Cambios en el BOE: `uv run python -m trafico_agent.watch` (sale con 3 si hay bloques nuevos). Tras reindexar, `--guardar` actualiza `data/versiones.json` y el CHANGELOG. GitHub Actions lo lanza cada lunes y abre un issue.
- Demo (`web.py`, FastAPI + HTMX) en Render (`render.yaml`): `TRAFICO_LLM=api` (API compatible con OpenAI; Groq; modelo en `TRAFICO_API_MODELO`, clave en `TRAFICO_API_KEY`) y `TRAFICO_BUSQUEDA=bm25` (sin bge-m3, cabe en 512 MB). HF Spaces Docker exige PRO y la cuenta HF gratis no tiene créditos de inferencia. Evaluar la config de la demo: `TRAFICO_BUSQUEDA=bm25 uv run python eval/run_agent.py --modelo api:openai/gpt-oss-120b`.
